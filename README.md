# ShadowFox Data Science Internship

This repository contains the projects completed as part of my **Data Science Internship at ShadowFox**.

The projects demonstrate practical skills in data visualization, data analysis, exploratory data analysis, statistical analysis, and business insights using Python.

## Internship Tasks

### Task 1 – Visualization Library Documentation

**Topic:** Matplotlib and Seaborn Visualization

This project documents commonly used visualization techniques using Python libraries such as Matplotlib and Seaborn.

**Topics covered:**
- Line charts
- Bar charts
- Scatter plots
- Histograms
- Pie charts
- Box plots
- Heatmaps
- Comparison of Matplotlib and Seaborn

**Tools:** Python, Matplotlib, Seaborn

---

### Task 2 – Delhi AQI Analysis

**Topic:** Delhi Air Quality Analysis

This project analyzes air-quality data from Delhi to understand pollutant concentrations and pollution patterns.

**Analysis includes:**
- Data exploration and cleaning
- Missing-value and duplicate checking
- Statistical analysis
- Pollutant-wise comparison
- Hourly pollution analysis
- Daily pollution trends
- Correlation analysis
- Visualization of PM2.5 and PM10
- Key environmental observations

**Tools:** Python, Pandas, NumPy, Matplotlib, Seaborn

---

### Task 3 – E-Commerce Sales, Profitability & Customer Insights Analysis

**Topic:** E-Commerce Sales and Profitability Analysis using Python

This project analyzes the Superstore Sales dataset to identify sales and profitability patterns and generate useful business insights.

**Analysis includes:**
- Data exploration and cleaning
- Sales and profit trends
- Category-wise analysis
- Sub-category performance
- Regional analysis
- Customer segment analysis
- Discount vs. profit analysis
- Top and bottom performing sub-categories
- Correlation analysis
- Year-wise sales and profit analysis
- Business recommendations

**Tools:** Python, Pandas, NumPy, Matplotlib, Seaborn, Google Colab
